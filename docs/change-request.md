# Запрос на изменение

| Поле | Содержание |
|---|---|
| Название | Перенос записи на другое занятие |
| Причина | В текущем описании есть только запись и отмена. Перенос позволит клиенту выбрать другое время без отдельной отмены. |
| Какие требования добавятся | Клиент может перенести свою подтверждённую запись до начала занятия на другое предстоящее занятие со свободным местом. Если перенос не удался, прежняя запись сохраняется. |
| Что нужно изменить | Дополнить требования и модуль бронирования. В классе Booking предусмотреть смену занятия с проверкой свободного места; питомец остаётся тем же. Обновить архитектуру и диаграмму записи, добавить сценарий переноса и тест-кейсы: успешный перенос; отказ при отсутствии мест; запрет переноса после начала занятия. |
| Новая версия | 1.2.0 — планируется новая возможность. В текущую версию перенос не включён. |

При переносе сохраняются владелец и питомец. Новое занятие должно ещё не начаться. Наличие места повторно проверяется при сохранении; при отказе старая запись остаётся подтверждённой. Если у питомца уже есть активная запись на выбранное занятие, перенос отклоняется.

Запрос описывает будущую функцию. Требования базовой версии и работа приложения в этом задании не изменяются.
