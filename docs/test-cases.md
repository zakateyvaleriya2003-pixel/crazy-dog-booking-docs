# Тест-кейсы

Набор предназначен для будущей проверки приложения. Статус всех тест-кейсов — «Не выполнялся»: в задании 1 ведётся документация, а не создаётся работающая система. Данные условные: клиент А, клиент Б, питомцы Рекс и Луна.

| Код | Связь | Предусловия и действия | Ожидаемый результат |
|---|---|---|---|
| TC-01 | FR-03, UC-01 | В расписании есть занятия на разные даты. Выбрать дату и вид занятия | Показаны только занятия по выбранным условиям; видны зал, кинолог, время и свободные места |
| TC-02 | FR-04, UC-01 | У клиента А есть Рекс; доступно 2 места. Выбрать занятие и Рекса, подтвердить | Создана одна запись «Подтверждена», осталось 1 место; клиент видит номер записи |
| TC-03 | FR-05, UC-01 | У Рекса уже есть подтверждённая запись. Повторить запрос | Второе активное бронирование не создано; свободных мест не стало меньше |
| TC-04 | FR-05, UC-01 | Осталось 1 место. Клиенты А и Б одновременно подтверждают запись разных питомцев | Подтверждена ровно одна запись; второму клиенту показано отсутствие мест; вместимость не превышена |
| TC-05 | FR-06, UC-02 | Есть предстоящая подтверждённая запись Рекса. Отменить и повторить отмену | Статус «Отменена»; место освобождено один раз; запись остаётся в истории |
| TC-06 | FR-01, UC-02 | Клиент Б отправляет запрос отмены записи клиента А по её идентификатору | Доступ отклонён; чужая запись и количество мест не изменены |
| TC-07 | FR-06, UC-02 | Занятие началось или запись завершена. Отправить запрос отмены | Отмена отклонена, статус и доступность мест не изменены |
| TC-08 | FR-07, UC-03 | Уже есть занятие 10:00–11:00. Создать занятие 10:30–11:30 с тем же кинологом или залом | Сохранение отклонено; указана причина конфликта; заполненные данные сохранены в форме |
| TC-09 | FR-08, UC-04 | У кинолога есть своё и чужое занятие; в своём есть отменённая запись. Открыть участников | Для своего занятия видны только активные записи; доступ к чужому занятию отклонён |
| TC-10 | FR-09, UC-01 | При подтверждении оборвать соединение до получения ответа | Нет ложного сообщения об успехе; данные формы сохранены; после восстановления связи можно проверить «Мои записи» |
| TC-11 | FR-02 | Отправить карточку питомца без клички, затем заполнить её | Без клички показана ошибка и сохранение отклонено; после заполнения карточка сохраняется |
| TC-12 | NFR-02, UC-01 | Открыть запись при ширине экрана 360 px; пройти шаги с клавиатуры | Нет горизонтальной прокрутки страницы; поля и кнопка подтверждения доступны, фокус виден |

Связи FR → UC → TC позволяют при изменении требования найти сценарий и проверки, которые тоже потребуется обновить. Фактические результаты и сведения о среде добавляются после выполнения тестов на приложении.
