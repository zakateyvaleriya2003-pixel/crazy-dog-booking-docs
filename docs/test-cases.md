# Тест-кейсы

Набор предназначен для будущей проверки приложения. Статус всех тест-кейсов — «Не выполнялся»: в заданиях 1 и 2 ведётся документация, а не создаётся работающая система. Данные условные: клиент А, клиент Б, питомцы Рекс и Луна.

| Код | Связь | Предусловия и действия | Ожидаемый результат |
|---|---|---|---|
| TC-01 | FR-03, UC-01 | Есть занятия разных дат и видов. Задать одновременно дату и вид; затем оставить только один фильтр | При двух фильтрах выполняются оба условия; незаданный фильтр не ограничивает список; показаны время, зал, кинолог и свободные места |
| TC-02 | FR-04, UC-01 | У клиента А есть Рекс; доступно 2 места. Выбрать занятие и Рекса, подтвердить | Создана одна запись «Подтверждена», осталось 1 место; клиент видит номер записи |
| TC-03 | FR-05, UC-01 | У Рекса уже есть подтверждённая запись. Повторить запрос | Второе активное бронирование не создано; свободных мест не стало меньше |
| TC-04 | FR-05, UC-01 | Осталось 1 место. Клиенты А и Б одновременно подтверждают запись разных питомцев | Подтверждена ровно одна запись; второму клиенту показано отсутствие мест; вместимость не превышена |
| TC-05 | FR-06, UC-02 | Есть предстоящая подтверждённая запись Рекса. Отменить и повторить отмену | Статус «Отменена»; место освобождено один раз; запись остаётся в истории |
| TC-06 | FR-01, UC-02 | Клиент Б отправляет запрос отмены записи клиента А по её идентификатору | Доступ отклонён; чужая запись и количество мест не изменены |
| TC-07 | FR-06, UC-02 | Занятие началось или запись завершена. Отправить запрос отмены | Отмена отклонена, статус и доступность мест не изменены |
| TC-08 | FR-07, UC-03 | Уже есть занятие 10:00–11:00. Создать занятие 10:30–11:30 с тем же кинологом или залом | Сохранение отклонено; указана причина конфликта; заполненные данные сохранены в форме |
| TC-09 | FR-08, UC-04 | У кинолога есть своё и чужое занятие; в своём есть отменённая запись. Открыть участников | Для своего занятия видны только активные записи; доступ к чужому занятию отклонён |
| TC-10 | FR-09, UC-01 | Проверить два случая: запрос не дошёл до сохранения; сервер сохранил запись, но ответ потерян. Восстановить связь и открыть «Мои записи» перед повтором | В обоих случаях нет ложного успеха, показано «Результат не подтверждён», ввод остаётся в текущей форме. В первом случае записи нет и повтор допустим; во втором найдена одна сохранённая запись, повтор не создаёт дубликат |
| TC-11 | FR-02, UC-05 | Авторизованный клиент отправляет карточку с пустой кличкой, затем с кличкой из пробелов | Оба сохранения отклонены; указана ошибка клички; данные других полей сохранены в форме |
| TC-12 | NFR-02, UC-01 | Открыть запись при ширине экрана 360 px; пройти шаги с клавиатуры | Нет горизонтальной прокрутки страницы; поля и кнопка подтверждения доступны, фокус виден |

| TC-13 | FR-07, UC-03 | Есть занятие 10:00–11:00. Создать занятие 11:00–12:00 с тем же залом и кинологом, вместимостью 5 | Занятие сохраняется и видно в расписании; совпадение окончания и начала не считается пересечением |
| TC-14 | FR-07, UC-03 | Отдельно отправить: окончание равно началу или раньше; вместимость 0, −1 или 2,5 | Каждый неверный вариант отклонён; указана причина; значения формы сохранены |
| TC-15 | FR-10, UC-06 | Администратор завершает подтверждённую запись после окончания; повторяет. Отдельно проверяет попытку до окончания, для отменённой записи и от роли клиента или кинолога | Первый переход даёт «Завершена», повтор ничего не меняет; остальные варианты отклонены |
| TC-16 | FR-01, FR-02, UC-05 | Клиент А создаёт своего питомца с кличкой « Рекс », возрастом 0 месяцев и пустыми необязательными полями; затем изменяет карточку. Клиент Б пытается изменить её по идентификатору | Кличка сохранена как «Рекс», возраст 0 принят; владелец может изменить данные; чужое изменение отклонено |
| TC-17 | FR-05, FR-09, UC-01 | Задержать ответ на подтверждение. Попытаться нажать кнопку повторно и отдельно повторить запрос напрямую | Во время ожидания показано «Сохранение», кнопка заблокирована; сервер допускает не более одной активной записи этой пары питомец–занятие |
| TC-18 | FR-03, UC-01 | Выбрать сочетание даты и вида без совпадений, затем сбросить фильтры | Показано «Занятия не найдены» и действие сброса; после сброса оба условия сняты и список обновлён |
| TC-19 | FR-02, UC-05 | Проверить клички длиной 1, 60 и 61 символ после удаления крайних пробелов; возраст не задан, 0, −1 и 1,5 месяца | Клички 1 и 60 приняты, 61 отклонена. Пустой возраст и 0 приняты; отрицательный и дробный возраст отклонены |

Связи FR → UC → TC позволяют при изменении требования найти сценарий и проверки, которые тоже потребуется обновить. Фактические результаты и сведения о среде добавляются после выполнения тестов на приложении.
