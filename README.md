# Веб-система бронирования занятий в кинологическом центре Crazy Dog

Система предназначена для записи владельцев собак на занятия и ведения расписания кинологического центра «Crazy Dog». Клиент выбирает занятие и питомца, кинолог просматривает своё расписание, а администратор управляет занятиями и записями. Репозиторий содержит проектную документацию; программный код в рамках задания 1 не разрабатывается.

## Работа с репозиторием

Основная ветка — `main`. Небольшие изменения оформляются в отдельной ветке, проверяются на согласованность с требованиями и затем сливаются в `main`.
